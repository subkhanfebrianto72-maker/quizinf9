Pengaturan Google Apps Script Database

Masukkan Web App URL hasil deployment dari Google Apps Script untuk menyimpan nilai ujian.

Langkah-Langkah Integrasi:

  1. Buat Google Spreadsheet baru di Google Drive Anda.
  2. Buka menu Ekstensi > Apps Script.
  3. Hapus semua kode yang ada, lalu salin (copy) kode Apps Script di bawah ini:
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // Header jika sheet masih kosong
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Waktu Selesai", 
        "Nama Siswa", 
        "Kelas", 
        "No Absen", 
        "Sekolah", 
        "Nilai Akhir", 
        "Jawaban Benar", 
        "Total Soal"
      ]);
    }
    
    // Tambah Baris Hasil Ujian Siswa
    sheet.appendRow([
      new Date(),
      data.nama,
      data.kelas,
      data.noAbsen,
      data.sekolah,
      data.skor,
      data.jumlahBenar,
      data.totalSoal
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({"status": "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({"status": "error", "message": error.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Klik Terapkan (Deploy) > Terapkan sebagai aplikasi web (New Deployment).
  2. Pada Who has access (Siapa yang memiliki akses), pilih "Anyone" (Siapa Saja).
  3. Klik Deploy, izinkan otorisasi akun Google Anda, lalu salin Web App URL yang dihasilkan ke input kotak di atas.
